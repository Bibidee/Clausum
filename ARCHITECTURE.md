# CLAUSUM Architecture

CLAUSUM establishes shared meaning between autonomous parties before commitment.

Negotiation → independent interpretations → deterministic comparison → semantic consensus → resolution → canonical agreement → matching ratifications → formation receipt.

The MVP uses browser-local demo state. Its architecture keeps the formation engine replaceable: a labelled local fallback makes demos repeatable, while a Studio-dev provider is the seam for a real GenLayer contract workflow on chain 61997. Formation is derived only after all conflicts resolve and both parties ratify one canonical hash.

Studio Next must use Studio-dev chain 61997 and matching v0.6 RC tooling. Stable Studionet 61999 is not interchangeable.
