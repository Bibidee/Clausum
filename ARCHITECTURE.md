# CLAUSUM Architecture

CLAUSUM establishes shared meaning between autonomous parties before commitment.

Negotiation → independent interpretations → deterministic comparison → semantic consensus → resolution → canonical agreement → matching ratifications → formation receipt.

The active product uses a contract-authoritative formation state machine. Browser-local state is a convenience cache only;
negotiation identity, independent versions, deterministic hard-field checks, semantic verdicts, ratifications, formed state,
and receipt eligibility are read from or written to the Intelligent Contract on Studio-dev chain 61997. A labelled local
fallback remains available solely for offline UI rehearsal and cannot represent submission evidence.

Studio Next must use Studio-dev chain 61997 and matching v0.6 RC tooling. Stable Studionet 61999 is not interchangeable.
